# MY edit DESIGN Portfolio

## 구성
- index.html : 포트폴리오 메인 사이트
- style.css : Pretendard + #f9f6f6 / #2c2c2c / #cf1919 디자인
- script.js : 작업물 카드/팝업 렌더링
- admin.html : 작업물 추가/수정/삭제 관리자 페이지

## 실행
index.html을 브라우저에서 열면 됩니다.

## 관리자
- 주소: admin.html
- 비밀번호: 1111
- 작업물 이미지는 이미지 URL을 입력하는 방식입니다.
- 데이터는 브라우저 localStorage에 저장됩니다.

## 중요한 점
현재 admin은 "정적 HTML 데모용"입니다. 비밀번호가 JavaScript에 들어 있기 때문에 실제 공개 서버에서 보안 인증으로 사용할 수 없습니다.
실서비스에서 여러 기기에서 관리자 수정 내용을 공유하려면 Firebase/Supabase/자체 서버 등의 DB + 인증을 붙이는 것을 권장합니다.

## 작업물 교체
admin.html에서 이미지 URL을 넣고 작업물을 저장하면 index.html의 해당 카테고리에 즉시 반영됩니다.


[영상 포트폴리오 사용법]
- 관리자에서 상세 타입을 'YouTube 영상'으로 선택합니다.
- 썸네일 이미지 URL을 입력합니다. 카드에는 이 썸네일만 표시됩니다.
- YouTube 영상 URL을 일반 watch/shorts/youtu.be 형식 그대로 붙여 넣습니다.
- 영상 비율에서 16:9 또는 9:16을 선택합니다.
- 작업명, 날짜, 한 줄 설명, 상세 내용, 태그는 이미지 작업과 동일하게 입력합니다.
- 사이트 팝업에서는 YouTube 영상이 원본 비율을 유지하며 고정된 미디어 영역 안에서 표시됩니다.
- 기존에 저장한 이미지 작업물은 자동으로 '이미지' 타입으로 유지됩니다.
